# Get Available Windows Updates

## Instructions

[How to use this repository](../../README.md)

## Description

Installs the PSWindowsUpdate module, then runs Get-WindowsUpdate. This returns all updates that are currently available.

## Compatibility

* **PDQ Inventory**: Yes
* **PDQ Connect**: Yes, use `Get Available Windows Updates (Connect).ps1` (untested; self-contained single file)

## Parameters

### WSUS

Specify to check WSUS for updates.
