# Windows Update Last Installed

## Instructions

[How to use this repository](../../README.md)

## Description

Installs the PSWindowsUpdate module, then runs the following cmdlets:
* Get-WULastResults
* Get-WURebootStatus

## Compatibility

* **PDQ Inventory**: Yes
* **PDQ Connect**: Yes, use `Windows Update Last Installed (Connect).ps1`
